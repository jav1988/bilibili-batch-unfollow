# B站关注批量整理

一个本地加载的 Chrome 扩展，用于读取当前 B 站账号的关注列表，经过搜索、筛选与勾选后，限速批量取消关注。

## 功能

- 复用当前 `bilibili.com` 页面的登录态，不保存 Cookie、密码或令牌
- 自动分页读取自己的关注列表
- 按昵称、UID、签名进行模糊搜索
- 当前筛选结果全选、逐项勾选
- 取消关注前二次确认
- 每次操作后重新生成随机间隔，可选 0.8～1.5、1.2～2.2、2～4、2.5～5.5、4～8 秒
- 对不同间隔显示高风险、较高风险、常规、推荐等分级提示
- 实时显示处理进度与下一次等待时间
- 连续失败 3 次自动停止，避免继续密集请求
- 失败后保留失败项，便于核查和重试
- 原创多尺寸插件图标，适配工具栏与扩展管理页
- 关闭弹窗后自动保存列表、搜索词、随机区间和勾选状态，再次打开可恢复
- 使用插件内美化确认与结果弹窗，明确显示人数、间隔、风险和失败详情

## 安装

1. 使用 Chrome 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹 `bilibili-batch-unfollow`。
5. 打开并登录 `https://www.bilibili.com/`。
6. 点击扩展图标，再点击“读取关注列表”。

## 安全说明

- 代码仅向 B 站官方网页接口发起请求。
- 所有请求都在用户主动打开的 B 站标签页中执行。
- 扩展不会上传、导出或持久化登录凭据；本地仅保存关注列表、搜索词和勾选状态。
- Chrome 弹窗关闭后，尚未完成的批量任务会暂停；再次打开后可从保留的失败或未处理项继续。
- 批量取消关注不可自动恢复，请先少量选择并验证。
- 请求过快可能触发网站风控，默认随机间隔为 2.5～5.5 秒；0.8～1.5 秒和 1.2～2.2 秒属于高风险选项，仅建议极少量操作。随机等待只能降低请求过密风险，不能保证账号不受限制。

## 技术说明

- 作者：马小战
- 版本：1.2.1
- 默认字体：`Fira Code`、`MesloLGS Nerd Font Mono`、`DejaVu LGC Sans Code`、`Roboto Mono`、`Noto Sans SC`、`monospace`
- 清单：Manifest V3
- 最低建议：Chrome 88+
- 数据接口：`/x/web-interface/nav`、`/x/relation/followings`
- 操作接口：`/x/relation/modify`

> Chrome 49 不支持 Manifest V3。现代 Chrome 已逐步停用 Manifest V2，因此本项目优先保证当前浏览器可安装性。
